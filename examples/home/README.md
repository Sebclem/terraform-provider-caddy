# Active home configuration

This typed example covers the 49 active sites resolved from the legacy inventory, including dotted hostname stems, alias inheritance, TLS, auth/access order, WebDAV methods and Jellyfin's `/metrics` access check and proxy continuation. `sites.tf` contains native typed HCL values generated by `scripts/generate-home-example.py` from the sanitized fixture; the provider itself does not read YAML, JSON or Caddyfile inputs.

Before use, follow [the local installation instructions](../../README.md) and [migration runbook](../../docs/migration.md). Supply `caddy_endpoint` and `basic_auth_accounts` (VMagent's vm/grafana/opnsense/admin bcrypt hashes) through your protected variable workflow. Default certificate, error-page and log paths refer to the Caddy host. Provision files and writable log directories externally. Backend addresses remain the inventory's private static addresses; review them before a real cutover.

The example enables certificate serving/redirects with issuance disabled. Certificate groups cover separate SNI names, as in the fixture. Renewal and reload after same-path file changes remain external. There is one explicit default-log filter owner and one log binding per hostname. Existing ID-less Caddyfile objects must be removed during the controlled rebuild, not imported.

`TestAccHomeRebuild` copies this exact example into an isolated fixture, replaces all upstreams/auth with local test servers, supplies synthetic certificates and password hashes, and checks behavior before/after rebuilding and after operator recovery. No production service is contacted. See [testing](../../docs/testing.md).
